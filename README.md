# TG BOT

Проект для разработки Telegram-бота, который можно настраивать для разных клиентов.

## Статус

Мы выбираем первый сценарий бота и проверяем, кому он нужен. Бот для записи клиентов — рабочая гипотеза, а не утверждённое требование.

## Работа по направлениям

- `docs/product-brief.md` — цели, аудитория, сценарии и критерии готовности.
- `docs/design/` — тексты, схема диалогов и требования к интерфейсу.
- Код появится после выбора первого сценария и согласования минимального набора функций.

## Следующие решения

1. Выбрать тип первого бота и целевого покупателя.
2. Описать минимальный сценарий и способ настройки для следующего клиента.
3. Определить хранение данных, развёртывание и поддержку.
4. Настроить удалённый Git-репозиторий, чтобы работать с двух компьютеров.
