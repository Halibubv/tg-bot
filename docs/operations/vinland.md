# ВИНЛАНД: эксплуатация и API

## Режимы запуска

`APP_MODE=demo` — локальный режим без токена. Он всегда слушает только `127.0.0.1`, `::1` или `localhost`, использует отдельную БД `vinland-demo.sqlite` и никогда не запускает отправку Telegram-напоминаний.

`APP_MODE=production` — требует `TELEGRAM_BOT_TOKEN`, `WEB_APP_URL` c HTTPS и `TELEGRAM_WEBHOOK_SECRET`. Секреты передаются окружением процесса, не клиенту и не в Git. Production API отвергает отсутствующие, поддельные, просроченные или повторяющиеся поля `initData` Telegram Mini App.

## Подключение собственного бота

1. Разверните приложение за HTTPS-прокси. `WEB_APP_URL` должен указывать на публичный адрес Mini App, а маршрут `https://<ваш-домен>/telegram/webhook` — проксироваться к этому же серверу. Локальный demo-адрес не подходит для Telegram.
2. Создайте своего бота через BotFather и задайте `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`, `APP_MODE=production` только в окружении сервера. Не отправляйте токен в чат и не коммитьте `.env`.
3. Зарегистрируйте webhook через официальный метод [setWebhook](https://core.telegram.org/bots/api#setwebhook): `url=https://<ваш-домен>/telegram/webhook`, `secret_token` должен совпадать с `TELEGRAM_WEBHOOK_SECRET`. Затем проверьте ответ [getWebhookInfo](https://core.telegram.org/bots/api#getwebhookinfo).
4. Откройте личный чат с ботом и отправьте `/start`. Бот должен показать кнопку открытия ВИНЛАНД. Проверьте сохранение дня в Mini App и приход напоминания на тестовом аккаунте.

Шаги с реальным токеном и Telegram-аккаунтом в текущей разработке не выполнялись. Для работы кнопки используется официальный [скрипт Telegram Mini Apps](https://core.telegram.org/bots/webapps#initializing-mini-apps), подключённый до кода интерфейса; браузерное демо работает и без него.

## HTTP-контракт Mini App

Все маршруты Mini App имеют префикс `/api` и в production требуют свежий заголовок `X-Telegram-Init-Data`. Извлечённый и проверенный Telegram ID задаёт единственную область данных пользователя.

| Метод и маршрут | Назначение |
| --- | --- |
| `GET /api/today` | Состояние сегодняшнего дня. |
| `PUT /api/today/workout` | Сохраняет `status`: `unplanned`, `planned`, `completed` или `rest`. |
| `PUT /api/today/nutrition` | Атомарно сохраняет `kcal`, `proteinG`, `fatG`, `carbsG`. |
| `GET /api/journal?weekOf=YYYY-MM-DD` | Неделя понедельник–воскресенье и сводка. |
| `GET /api/journal/day?date=YYYY-MM-DD` | Детали дня, только чтение для журнала. |
| `GET/PUT /api/settings` | Часовой пояс, включение и первое время напоминания. |
| `POST /api/onboarding` | Отмечает завершение первого запуска. |

Каждое изменяющее действие требует `Idempotency-Key` из 8–120 безопасных символов. Повтор с тем же телом возвращает сохранённый результат; повтор ключа с иным телом возвращает `409`.

## Данные и восстановление

SQLite находится в `DATA_DIRECTORY`. Не запускайте два экземпляра приложения с одним файлом БД. Перед файловой резервной копией остановите приложение и копируйте основной файл вместе с `-wal`/`-shm`. Восстанавливайте сначала в отдельный каталог и проходите `node --test` плюс ручное чтение записи в demo.

## Будущая синхронизация с сайтом

Синхронизация пока отсутствует и интерфейс не показывает её как работающую. Будущий контракт должен отдельно согласовать: подтверждение Telegram-аккаунта на сайте, одностороннее или двустороннее направление данных, версионирование записей, разрешение конфликтов, отзыв привязки и срок хранения. До этого API ВИНЛАНД остаётся самостоятельным и не принимает данные веб-аккаунта.
