# ВИНЛАНД — дизайн Telegram Mini App

**Статус:** редактируемый дизайн-черновик, 29 сентября 2026 года. Это самостоятельный MVP-компаньон для отметки тренировок и дневных итогов КБЖУ. Синхронизации с веб-приложением сейчас нет. [Открыть локальный прототип](index.html) · [Поля и состояния для реализации](IMPLEMENTATION-CONTRACT.md).

## Что уже решено

- Продукт выглядит как приложение внутри Telegram. Бот открывает Mini App и позднее доставляет напоминания.
- В одном дне есть тренировка и дневной итог КБЖУ. Тренировку можно запланировать **на сегодня** и отметить выполненной либо выбрать «Сегодня без тренировки». Последний вариант — завершённое, нейтральное состояние дня.
- Напоминание о запланированной тренировке предварительно приходит не чаще двух раз в день с интервалом 12 часов. Точный режим ещё требует проверки с пользователями.
- В будущем пользователь сможет привязать Telegram к аккаунту сайта ВИНЛАНД. В текущем интерфейсе это только объяснение будущей функции без кнопки, имитирующей подключение.

## Карта экранов

```text
Первый запуск → короткое знакомство → Сегодня
Сегодня → запланировать на сегодня → отметить выполнено / сегодня без тренировки
Сегодня → внести или исправить КБЖУ → Сегодня
Сегодня → Журнал → неделя → детали дня → назад к неделе
Сегодня → Настройки → напоминания / время / часовой пояс
Настройки → будущая привязка к сайту (информация, действие недоступно)
```

Нижняя навигация из трёх пунктов: **Сегодня · Журнал · Настройки**. В деталях дня есть явная кнопка возврата в журнал. Любая запись показывает именно сохранённое состояние; интерфейс не обещает сохранения до его успешного завершения.

## Экраны и состояния

| Экран | Содержимое и действие | Пустое / крайнее состояние |
| --- | --- | --- |
| Первый запуск | Знак гор, короткое объяснение двух задач и кнопка «Начать». Вход не требует аккаунта сайта. | После «Начать» открывается «Сегодня» без фиктивных данных. |
| Сегодня: нет плана | Дата в выбранном часовом поясе; тренировка «Не запланирована»; кнопки «Запланировать на сегодня» и «Сегодня без тренировки». Ниже — КБЖУ. | Четыре показателя КБЖУ — прочерки, не нули. |
| Сегодня: план | Статус «Запланирована»; действия «Выполнено» и «Сегодня без тренировки». | Повторное действие не создаёт вторую запись. |
| Сегодня: результат | «Выполнено» или «День без тренировки»; «Изменить отметку» возвращает выбор действий. | Напоминания о тренировке на этот день прекращаются. |
| Ввод КБЖУ | Отдельный экран формы: калории, белки, жиры, углеводы. «Сохранить» и «Отмена». Повторное открытие подставляет сохранённые значения. | Пустое поле не равно нулю; ошибка появляется возле поля с ясным правилом исправления. |

| Детали дня | Дата, состояние тренировки и четыре показателя питания. Для сегодняшнего дня можно вернуться к редактированию. | Отсутствующие данные подписаны «Не внесено», без оценки пользователя. |
| Настройки | Включение напоминаний, первое время, рассчитанное второе время (+12 часов), часовой пояс IANA; сохранение. | При выключенных напоминаниях поля времени неактивны. Изменение часового пояса может сменить текущую календарную дату; старые записи остаются на исходных датах. |

## Поведение и тексты

- Обращение нейтральное, короткое и спокойное. «День без тренировки» не помечается ошибкой или провалом. Отсутствие записи тоже нейтрально.
- При смене «Выполнено» ↔ «День без тренировки» новое состояние заменяет предыдущее. Отмена изменения возвращает к сохранённому состоянию. Удаление отметки через явное «Сбросить отметку» возвращает к «Не запланирована» и требует подтверждения.
- После сохранения КБЖУ показывается сохранённый итог. Если сохранить не удалось, введённые числа остаются в форме и выводится «Не удалось сохранить. Попробуйте ещё раз».
- Неделя начинается в понедельник. Итог не использует оценочные проценты, цели или рекомендации: они не заданы.
- Страница дня из журнала показывает прошлые дни без режима редактирования. Планирование и исправление доступны только для сегодняшней даты; расширение на прошлые дни решается отдельно.
- Время напоминаний относится к тренировке со статусом «Запланирована». Если пользователь отметил выполнение или день без тренировки, повторять напоминание в этот день не нужно. Доставка уведомлений ботом не реализована в прототипе.

## Визуальный язык

- Сохранены графитовая основа, холодный светлый текст, один ледяной акцент и минимальный знак гор из предыдущего одобренного эскиза. Знак в прототипе условный; фирменный логотип потребуется подставить отдельно.
- `Jura` используется для логотипа, коротких заголовков и разделов: угловатый кириллический рисунок даёт рунический оттенок. Текст действий, пояснения, поля и числа набраны обычным читаемым гротеском. Буквальные руны не используются вместо русских букв.
- Экран строится вертикально: один главный смысл на область, тонкие разделители, без набора одинаковых карточек. Статусы всегда подписаны словами; цвет не служит единственным сигналом.
- Целевой экран — узкий мобильный Telegram Mini App. Прототип проверяется на 320, 375, 414 и 768 px, с клавиатурой и без обязательного наведения мыши.

## Ограничения черновика и вопросы для утверждения

1. Для силовой тренировки пока фиксируется факт, а не упражнения, подходы и веса. Нужно подтвердить, достаточно ли этого для первого полезного релиза.
2. КБЖУ пока вводятся четырьмя итоговыми числами за день, без отдельных приёмов пищи и расчёта калорий из БЖУ.
3. Интервал 12 часов был предложен предварительно. Нужно утвердить начальное время, допустимый поздний час и нужны ли напоминания о КБЖУ.
4. Нужно решить, разрешать ли задним числом исправлять прошлые дни. В черновике журнал только показывает историю.
5. Для настоящей связи с веб-аккаунтом нужны отдельный сценарий авторизации, правила конфликта данных и решение о хранении. До этого связь не отображается как работающая.

## Как открыть прототип

Откройте `index.html` в браузере. Это локальный интерактивный макет: данные сохраняются только в хранилище этого браузера. Блок «Режимы прототипа» под экраном позволяет сбросить пример и вызвать ошибку сохранения для проверки. Никаких сообщений в Telegram и синхронизации с сайтом он не выполняет.

В выпадающем списке часовых поясов макет показывает несколько примеров и зону устройства. В рабочем приложении потребуется полный выбор поддерживаемых зон IANA.

## Проверка прототипа

В Chrome проверены первый запуск, все переходы отметки тренировки, сброс и его отмена, ввод/правка КБЖУ, некорректные поля, имитация ошибки записи, пустой и заполненный журнал, детали дня, настройки и сохранение после перезагрузки. Проверены ширины 320, 375, 414 и 768 px; при высоте 640 px нижняя навигация остаётся видимой. Проверены фокус после действий, клавиша Escape в подтверждении и контраст основных пар текста и фона. Это проверка дизайна-прототипа, не тест Telegram WebView, доставки уведомлений или серверного хранилища.
